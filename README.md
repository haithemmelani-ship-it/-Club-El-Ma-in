# 🌟 نادي المُعين - AL-MU'ĪN

## 🏛️ اللجان الأربع للنادي
1. 🧠 **اللجنة العلمية والتكوينية**: إعداد الورشات، الدورات التطبيقية، والمحاضرات الطلابية.
2. 📢 **اللجنة الثقافية والإعلامية**: تغطية الفعاليات، تصميم المواد البصرية، وتنظيم الأمسيات الفكرية.
3. 🤝 **اللجنة الاجتماعية والتطوعية**: تنظيم المبادرات التضامنية، الأنشطة الترفيهية، ودعم روح التعاون بالإقامة.
4. ⚙️ **لجنة التنظيم واللوجستيك**: تجهيز القاعات، إدارة المقاعد والحضور، وتنسيق الجداول الزمنية.

## 🎯 قيمنا الأساسية
* 🤝 **العون**: المساندة والتكافل بين الطلبة.
* ⏱️ **الانضباط**: الالتزام والمصداقية في العمل الجماعي.
* 💡 **المبادرة**: تشجيع الأفكار الفعالة والمبدعة.
* 👥 **الانتماء**: تعزيز روح الفريق والروابط الأخوية.
